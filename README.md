# 目標達成プランナー（プロトタイプ）

目標と目標日を入れると、AIが
1. 現状把握の質問を生成
2. Web検索で実例・統計を調べたうえで達成可能性とペースを判定し、タスクに分解
3. 毎日の進捗入力から再評価してペースを更新

する最小構成のアプリです。**Anthropic APIキーを設定するだけで動きます。**

## セットアップ

```bash
cd goal-app
npm install
cp .env.example .env
```

`.env` を開いて `ANTHROPIC_API_KEY` に自分のAPIキーを入れる（console.anthropic.com で取得）。

```bash
npm start
```

`http://localhost:3000` をブラウザで開けば使えます。

## 構成

```
goal-app/
  server.js        バックエンド（Anthropic API呼び出しを仲介）
  public/
    index.html      画面
    app.js          フロントのロジック（各ステップの状態管理・API呼び出し）
  .env.example      APIキー設定のテンプレート
```

## 使っているモデル

- `claude-haiku-4-5-20251001`：現状把握の質問生成（軽い処理なので安いモデル）
- `claude-sonnet-5`：計画生成・日次の再評価（判断が必要な処理）＋計画生成時はWeb検索も有効化

モデル名やAPIの仕様は変わることがあるので、エラーが出たら [Anthropic のドキュメント](https://docs.claude.com) で最新のモデル名・APIバージョンを確認してください。

## できること（完成版 v2）

- **複数の目標を並行管理**：「＋ 新しい目標」からいくつでも目標を追加でき、一覧画面（Mission Control）でまとめて状況を確認できます
- 目標＋目標日を入れるだけで、AIが現状把握の質問→達成可能性判定・ペース・タスク細分化までを自動生成
- **ペースリボン**：各目標の「開始〜目標日」の間で今どの位置にいるかを視覚化。色でペース状況（順調/要調整）が一目でわかります
- ブラウザの localStorage にすべての目標を保存。リロードしても消えません
- 各目標のダッシュボードから何度でもチェックインでき、AIがそのたびにペースを再評価。記録履歴も一覧表示
- 目標の削除も可能
- 専用デザイン（ダークトーン＋ゴールドアクセント、Space Grotesk / JetBrains Mono / Inter のタイプフェイス）

## 今のところ簡易的な部分（今後の拡張ポイント）

- **保存はこのブラウザだけ**：localStorage はブラウザ・端末ごとなので、別の端末からは見られません。複数端末で使うにはDB（SupabaseやFirebaseなど）＋アカウント機能への移行が必要です。
- **APIキーはサーバー側の環境変数のみで管理**：フロントには一切キーを渡さない設計なので、そのままデプロイしても安全です。
- **エラー処理は最小限**：JSON解析に失敗した場合など、AIの出力が想定形式からズレるケースのリトライ処理は未実装です。

## デプロイする場合

Vercel / Render / Railway などNode.jsが動くホスティングであればそのままデプロイ可能です。環境変数に `ANTHROPIC_API_KEY` を設定するのを忘れずに。
